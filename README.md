# مجلس (Bord)

منصة عربية لحوكمة مجالس الإدارة واللجان: الاجتماعات، والمحاضر، والقرارات، ومتابعة التنفيذ.

## التشغيل محلياً

```bash
pnpm install
cp .env.example .env.local   # ثم ضع إعدادات مشروع Supabase
pnpm dev
```

## الفحص

```bash
pnpm check   # lint + typecheck + tests
pnpm build
```

خطة البناء في [docs/PLAN.md](docs/PLAN.md)، وخطوات الإعداد في [docs/SETUP.md](docs/SETUP.md).
